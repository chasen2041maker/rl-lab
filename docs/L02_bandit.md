# 第 2 课：10 台老虎机，探索还是利用

**这课回答什么问题**：不知道哪个选择最好的时候，是一直用目前看着最好的那个（利用），还是花点机会去试别的（探索）？强化学习里每个算法都要回答这个问题，这一课用最简单的游戏把它单独拎出来。

- 你要写：`rl/bandit.py` 里两个函数，`update`（2 行）和 `choose`（3 行）
- 用时：一次坐下，30 分钟左右
- 做法：先跑参照、先猜，再写，再跑

## 游戏规则

10 台老虎机，每台中奖概率不一样（开局随机定好，你看不到）。拉一次：中奖得 1 分，不中得 0 分。一局拉 1000 次，看一共赢几次。

和倒立摆比，这里没有“状态”：每次面对的都是同样 10 台机器，只需要决定拉哪台。所以它是强化学习最简单的样子，只剩“动作”和“奖励”。

## 第 3 步：你来写 `update`（记账：更新这台的平均中奖率）

`Q[a]` 是第 a 台目前的平均中奖率，`N[a]` 是拉过几次。拉了第 a 台、得到 `r`（1 或 0）以后：

1. `N[a]` 加 1
2. `Q[a] += (r - Q[a]) / N[a]`

第 2 行的意思：新的平均 = 旧的平均 + (这次的结果 − 旧的平均) ÷ 次数。这次比平均好，平均就往上挪一点；拉的次数越多，每次挪得越少。这一行很重要，后面 Q-learning 的更新长得几乎一样。

## 第 4 步：你来写 `choose`（ε-贪心：选下一次拉哪台）

掷一次骰子 `rng.random()`（0 到 1 之间的随机数）：

- 小于 `epsilon`：探索，随便挑一台，`return int(rng.integers(len(Q)))`
- 否则：利用，挑目前平均最高的那台，`return argmax_random_tie(Q, rng)`

`epsilon`（ε）就是“拿多少比例的机会去探索”：0 = 从不探索，0.1 = 十次里有一次随便试，1 = 全靠随便拉。
